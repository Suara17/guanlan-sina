## UI优化

### 页面切换加载体验优化

**提交**: `10b3c3d` - feat(ui): 优化页面切换体验，使用顶部进度条替代全屏加载

**修改文件**: `frontend/App.tsx`

**改动内容：**
1. 新增 `LoadingBar` 组件 - 顶部细进度条，带动画效果
2. 使用 `useTransition` 实现页面切换时保持上一页内容显示
3. 首次加载使用简洁的顶部进度条，不再显示全屏"页面加载中..."

**效果：**
- 页面切换时：显示上一页面内容 + 顶部进度条
- 首次加载：只显示顶部进度条，不再有全屏遮罩

**代码关键点：**
```tsx
// 使用 useTransition 实现非阻塞导航
const [isPending, startTransition] = useTransition()

const handleNavigate = (path: string) => {
  startTransition(() => {
    navigate(path)
  })
  setSidebarOpen(false)
}

// LoadingBar 组件显示加载进度
<LoadingBar isLoading={isPending} />
```
